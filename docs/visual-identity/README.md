# Visual Identity

This section defines how Numena’s brand is expressed visually. It documents the principles, assets, and rules that guide the use of color, typography, logo, imagery, and layout across brand communications.

The goal is to create a recognizable and consistent visual identity without limiting its application to a single medium or format.

## Documents

| Document | Purpose |
|---|---|
| [`color.md`](./color.md) | Defines the brand color palette, the role of each color, and guidance for its use. |
| [`typography.md`](./typography.md) | Defines the typefaces, their roles, and the principles governing typographic hierarchy and use. |
| [`logo-system.md`](./logo-system.md) | Documents the logo assets, available variations, and rules for their application. |
| [`imagery.md`](./imagery.md) | Defines the principles for selecting, creating, and using imagery in brand communications. |
| [`layout.md`](./layout.md) | Establishes the principles for composition, spacing, alignment, hierarchy, and visual balance. |

## How to Use This Section

Use these documents when creating or reviewing brand materials, including the website, presentations, marketing assets, editorial content, and other communications.

Consult the relevant document for specific guidance. When a project requires decisions not covered by the current rules, document the decision and consider whether the guidelines need to be updated.

## Scope

This section covers Numena’s **visual identity**, not its complete brand strategy or product design system.

- **Brand strategy** defines Numena’s positioning, audience, purpose, differentiation, and intended perception.
- **Visual identity** translates the brand into a coherent visual language.
- **Design system** will define the reusable tokens, components, patterns, and implementation rules needed to apply visual decisions consistently across digital products.

The visual identity provides the foundation for future applications. It should remain consistent with the brand strategy while allowing appropriate flexibility across different contexts and formats.

## Maintenance

Keep these documents aligned as the identity evolves. Update the relevant guidelines whenever an approved change affects the palette, typography, logo, imagery, or layout principles.

The documentation should reflect the current approved identity rather than proposed or unvalidated directions.
